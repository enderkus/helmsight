# Değişiklik günlüğü

Değişiklik günlüğü yalnızca İngilizce tutulur; sürüm notları GitHub'daki
[sürümler sayfasında](https://github.com/enderkus/helmsight/releases) da
yayımlanır. Biçim [Keep a Changelog](https://keepachangelog.com/tr-TR/1.1.0/)
kurallarına, sürüm numaraları [Anlamsal Sürümleme](https://semver.org/lang/tr/)
kurallarına uyar. 0.x sürümleri arasında yapılandırma, API ve veritabanı
biçimi değişebilir; yükseltmeden önce ilgili sürümün notlarını okuyun.
